# NTU60 Label Mappings

Machine-readable mapping configs for NTU60 coarse supervision experiments.

Files:
- semantic_coarse_v1.csv / .json
- trajectory_coarse_v1.csv / .json
- semantic_vs_trajectory_comparison.csv

Conventions:
- All indices are 0-based.
- Row order follows NTU60 class order 1..60.
- JSON files include both class metadata and 60-length mapping arrays for direct training use.
