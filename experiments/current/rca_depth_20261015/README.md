# RCA stage 深度消融测速

2026-10-15，随机权重结构测速，无训练或准确率结论。
Current 为已完成实现优化的 RCA LocalT3，FFN4、anchors16、attn_drop0.1。
四个候选分别将一个 stage 深度从2改为1，其余保持2；各stage首个block及其下采样保留。

RTX4070 Laptop、FP32、TF32 off、CPU线程1、B1 T64 V14 M1。
eval/no_grad，80次预热、每轮额外10次，12轮×60次（每模型720次），轮换并反转顺序。
同步墙钟包括Python调度，不包括数据加载/H2D。所有候选通过CPU训练前向/反向有限值检查及GPU输出检查。

四个减层候选均比Current快约10.5%–11.9%；候选间仅约0.11ms差距，存在轮间波动，不作稳定排名。
S3本次平均耗时最低，比B0减少44.03%。
S1只减少105,591参数，S2/S3/S4各减少418,143参数；参数减少幅度不能推断精度损失大小。
建议后续若训练，可优先比较S1与S3：近似相同速度、不同删减位置和容量。仍需验证准确率，不能继承原LocalT3的88.8033%。

候选配置使用model.SkateFormer.SkateFormer并显式设置depths、channels、embed_dim，绕过工厂固定depths限制；
可直接用于main.py，但仅保存在本实验目录，使用独立work_dir，没有覆盖原模型或配置。
训练时depths变化也会改变原代码按总深度分配的DropPath日程（若drop_path非零），需在解释实验时考虑。
